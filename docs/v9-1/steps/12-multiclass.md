- **Зависит от:** шаг 11 (лист "Я", повышение уровня).

Если часть оказалась слишком большой, остановиться и записать это в отчёт.

## Часть 1. Данные мультикласса
**Цель:** Список классов члена отряда в модели и в колонке `classes` с миграцией, сводка `character_class`, `subclass`, `level` из списка, перенос списка в файле кампании и откат импорта.

**Читать (только это):** `DEV.md`: эпик M, разделы M.1, M.2, M.6. `DESIGN.md`: задача 21.

**Код (где работать):** пути от `shared/src/commonMain/kotlin/com/lyrismet/incadent/`.
- `feature/codex/domain/model/PartyMember.kt` (поле `classes`, модель `PartyClass`), новый файл чистых функций рядом в `feature/codex/domain` (сумма уровней, остаток до 20, сводка, добавление без повтора, сборка списка из старой сводки)
- `feature/codex/domain/repository/PartyRepository.kt`, `feature/codex/data/PartyRepositoryImpl.kt`, `sqldelight/com/lyrismet/incadent/db/PartyMember.sq` (колонка в `select`, `insert`, `update`; сводка пересчитывается при записи), адаптер колонки в `persistence/` (сверить с адаптером `vulnerabilities`)
- `feature/campaign/data/file/CampaignFile.kt`, `CampaignExporter.kt`, `CampaignImporter.kt`, `RecordValidator.kt`, `RecordDiff.kt`, `ImportRollback.kt`, `feature/campaign/domain/model/Campaign.kt` (список в файле, старые файлы без него читаются)
- `QuickRecords.kt` и места, где член отряда собирается из полей (`PartyRepositoryImpl.toDomain`, копия кампании), чтобы не потерять список

**Миграция и тесты:** `27.sqm` на `party_member`: `classes TEXT NOT NULL DEFAULT ''`, список хранится только при двух и более классах (бэкфилла нет, у одного класса колонка пуста). Тест миграции на базе версии 26 рядом с существующими (`persistence/SchemaMigrationTest.kt`), обмен файлом со списком и без, откат импорта, запись списка пересчитывает сводку. Тесты логики в `commonTest`. Имена в обратных кавычках без запятых и точек.

**Не трогать:** NPC и его класс, бой, текущие поля `characterClass`, `subclass`, `level` как сводку (их читают бой, обмен, поиск).

**Приёмка:**
- Старый персонаж открывается с одним классом, уровень тот же.
- Сохранённый список из двух классов даёт сводку: класс и подкласс первого, уровень сумма. Выгрузка и загрузка файла кампании сохраняют список, откат импорта возвращает старый.

**Готово, когда:** `docs/RULES.md` "Готовность задачи", `./gradlew build -x :shared:linkReleaseFrameworkIosArm64 -x :shared:linkReleaseFrameworkIosSimulatorArm64`, `ktlintFormat`, `detekt` зелёные, тесты на iOS-имена без запятых и точек.
