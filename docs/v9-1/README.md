# v9.1

Источник: issue #63 "Предложения для дизайна v9.1". Это карта шагов: по ней видно, что поручить агенту. Правила для всех
шагов в `docs/RULES.md`. Как устроен процесс: `docs/README.md`.

Поручить шаг: `/step` (следующий по очереди) или `/step N`. Один шаг это один бриф в `steps/` и один PR. Шаги делаются
по
порядку, если в строке "Зависит от" не сказано иное.

Файлы версии: `DESIGN.md` (требования, задачи дизайн-модели, статус дизайна, открытые вопросы), `DEV.md` (описание для
разработки, миграции, тесты, приёмка), `steps/` (брифы).

## Шаги

**Номера миграций.** Занято `13.sqm` и `14.sqm` (шаг 2), следующая свободная `15.sqm`. Номера в шагах ниже
ориентировочные:
агент берёт следующий свободный номер из `shared/src/commonMain/sqldelight/migrations/`. Файлы `databases/N.db` это
снимки
схемы, а не миграции: `15.db` лежит там после `14.sqm`, `15.sqm` создаст `16.db`.

### Шаг 1. Мелкие правки и игровое время боя

Статус: `[x]`. Зависит от: нет. Миграции: нет. Бриф: `steps/01-small-fixes-time.md`.

**Часть 1. Мелкие правки и ошибки**
Цель: Исправить ошибки и мелкие правки без новых экранов: временные хиты между листом "Я" и боем, курсор в
"Особенности", иконка "поделиться" и плавная панель упоминаний, универсальные тексты "Ресурсов", закрытие панели боя
смахиванием, проверка, что настройки режима правки записи нет.

**Часть 2. Игровое время и ход назад**
Цель: Заменить часы реального времени игровым временем `(раунд - 1) × 6 с` и добавить кнопку "‹" (предыдущий ход) в
карточку хода.

### Шаг 2. Участник боя: имя, роль, связь, слияние NPC

Статус: `[x]`. Зависит от: нет. Миграции: `13.sqm` (роль), `14.sqm` (флаг `is_label`: существо вида названо только для
этого боя) (журнала слияния в таблице нет, слияние возвращает снимок в памяти на окно Undo в 5 секунд). Бриф:
`steps/02-combatant-identity.md`.

**Часть 1. Участник боя: имя, роль, связь с кодексом**
Цель: Строка роли "вид · класс · подкласс", метка связи с кодексом, имя из кодекса вместо копии, переименование в бою,
поле "Роль" и кнопки "В кодекс" и "Связать с NPC".

**Часть 2. Слияние двух NPC с одним именем**
Цель: Кнопка "Объединить", когда введённое имя уже есть в кодексе: слияние записей NPC со всеми связями и Undo.

### Шаг 3. Очередь: неполная, правка, подсветка, средний уровень
