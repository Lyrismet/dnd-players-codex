# Шаг 10. Таб-бар и вкладка «Лист»
- **Кому:** агент-разработчик KMP (Compose Multiplatform, Circuit, Metro). Ревью: QA-агент. На устройстве: владелец (приложение Д п.1-3, крупный системный шрифт, нижняя панель с жестовой навигацией).
- **Цель:** в баре пять мест, «Я» по центру кругом 48 dp с нахлёстом 7 dp. Экран «Я» открывает лист своего персонажа: закреплённая шапка (портрет, имя, класс, хиты, плитки), вкладка «Лист» с шестью полосами, рядом значков, поиском, блоками «О персонаже» и «Личность», первое заполнение в четыре шага, выбор персонажа, если метки «я» нет. Формулы только из домена шага 9.
- **Перед началом (проверить, иначе остановиться и вернуть в шаг 9):** в `party_member` (`sqldelight/com/lyrismet/incadent/db/PartyMember.sq`) сейчас только `hp_max`, `hp_current`, нет временных хитов, КД, скорости, спасбросков от смерти (временные хиты есть только у участника боя, `Combatant.sq`, `temp_hp`). Приложение Б (`DESIGN_V9.md:599-617`, последняя строка) говорит, что это остаётся в записи отряда, значит шаг 9 должен был добавить поля. Имена моделей и репозиториев листа брать из PR шага 9.
- **Задачи:** 7.1 таб-бар (`DESIGN_V9.md:384-392`, пять мест, `BottomTabBar` получает параметр «центральный элемент»); 7.2 экран «Я» (`393-409`, шапка, хиты через `NumberPadSheet` без красной кнопки «Урон», пустой выбор, сворачивание шапки); 7.3 вкладка «Лист» (`410-450`, полосы, поиск, вдохновение, КД с «Откуда», «О персонаже», первое заполнение). Вкладки «Ресурсы», «Заклинания», «Вещи» только регистрируются, содержимое делают шаги 11-12; кнопку «Отдых» рисует шаг 12.
