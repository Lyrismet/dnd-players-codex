## Приёмка

1. Импорт файла "для друга": нет хитов, КД, заметок отряда, метки; повторный импорт того же файла - "Ничего нового".
2. Чужая личная копия: оба тумблера выключены, подпись без угадывания пола; метка локальной записи не меняется.
3. Сессия, совпавшая по дню и названию (у вас 6, в файле 4, общих 2): "Объединить заметки" даёт 8, "Оставить отдельно" добавляет вторую с пометкой "из файла".
4. "Взять всё из файла" ставит выбор всем конфликтам, каждый можно поменять; откат ("Отменить последний импорт") возвращает как было.
5. Удалил запись, импортировал файл с ней: не воскресла, видна в "Вы удаляли раньше", "Вернуть" работает; Undo удаления снимает надгробие.
6. Установка поверх базы v8: данные целы (приложение Д, сценарий 13).
