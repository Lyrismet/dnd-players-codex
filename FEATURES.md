## 4. Кодекс

- [x] 4 вкладки: **Отряд** / NPC / Квесты / Места, счётчик записей на каждой (Отряд пока заглушка — нет домена)
- [ ] Поиск по имени/расе/фракции/классу/игроку/награде/типу/региону (пока только по полям, реально существующим в
  модели — имя/описание NPC, название/награда/подавший квеста, название/тип локации)
- [x] Фильтры по статусу (свои для каждой вкладки: отряд — в составе/отсутствует, NPC — друг/враг/нейтрал/мёртв,
  квесты — активен/выполнен/провален), счётчик на каждом фильтре (для NPC и квестов — отряд/локации без статуса)
- [ ] Кнопка "+ Запись" — открывает форму создания (раздел 6) — кнопка есть по макету, но пока ничего не делает
- [ ] Карточка **отряда**: имя (+ "вы" если это игрок), класс/уровень/раса, статус, КД+HP
- [ ] Карточка **NPC**: инициал-аватар, имя (зачёркнуто если мёртв), раса+фракция, статус-бейдж, "упоминается в N
  сессиях" — аватар/зачёркивание/бейдж сделаны, раса+фракция и счётчик упоминаний ждут своих полей/фичи упоминаний
- [x] Карточка **квеста**: значок ромба, название, статус-бейдж, кто дал (кликабельная ссылка на NPC) + награда
- [ ] Карточка **локации**: значок, название, тип+регион, "кто здесь" (NPC с этой локацией) + счётчик сессий —
  значок/название/тип сделаны, региона в модели ещё нет
- [x] Пустое состояние поиска/фильтра

## 5. Карточка сущности (нижний лист)

Общее для всех 4 типов (party/NPC/quest/location):

- [ ] Эмблема (инициал для персонажей, значок для квеста/локации), заголовок, оверлайн-подпись типа+статуса
- [ ] Переключатель статуса прямо на карточке (кроме локации — у неё статуса нет)
- [ ] Описание
- [ ] Блок "фактов" (raса/фракция/КД/хиты/награда/регион...), некоторые поля — кликабельные ссылки на другие сущности
- [ ] Группы связанных сущностей (у NPC — "выдал квесты", у локации — "кто здесь"/"квесты")
- [ ] "Связанные заметки" — автопоиск сессий с упоминанием (см. раздел 3)

## 6. Форма создания записи в Кодексе

- [ ] Переключатель типа (Отряд/NPC/Квест/Место) прямо в форме
- [ ] Динамические поля по типу:
    - Отряд: тумблер "мой персонаж", имя, игрок, класс, раса, уровень/хиты/КД/бонус инициативы (степперы), состав
    - NPC: имя, раса, фракция, отношение (чипы), локация (чипы), заметки
    - Квест: название, кто дал (чипы по NPC), награда, где, статус, описание
    - Локация: название, тип, регион, описание
- [ ] Валидация (кнопка "Сохранить" активна только когда есть имя)
- [ ] Степпер открывает калькулятор (раздел 8) для быстрого ввода числа

## 7. Бой — подготовка

- [ ] Шаг 1: отряд из кодекса — чекбоксы вкл/выкл, текущие хиты, временные хиты (тап открывает калькулятор)
- [ ] Шаг 2: противники — добавление вручную (текстовое поле), из кодекса (враги-NPC), из офлайн-бестиария (моки:
  Скелет-лучник/Зомби/Гоблин/Культист)
- [ ] Автонумерация одинаковых противников (Скелет I, Скелет II...)
- [ ] Шаг 3: очерёдность — два режима (по словам мастера / по инициативе), переключается в Настройках
    - "По словам мастера": тап по участнику назначает следующий порядковый номер
    - "По инициативе": ввод числа (свой персонаж — можно бросить d20 прямо в приложении)
- [ ] Подсказка, что мешает начать бой (нет врагов / не всем назначена очередь)
- [ ] Кнопка "В бой" с живым лейблом состояния

## 8. Бой — активный раунд

- [ ] Заголовок: таймер боя, раунд, бейдж режима HP (скрытые/открытые), "Завершить бой"
- [ ] Полоса всех участников: инициатива/номер, имя+роль, индикатор стороны, HP-полоска (открытый режим) или пипсы
  ранений (скрытый режим), состояния-бейджи
- [ ] Баннер "врагов не осталось" с быстрым переходом к итогам
- [ ] Добавление подкреплений на лету (текстовое поле + подбор из бестиария по имени)
- [ ] Кнопка "Следующий ход →", автопропуск выбывших участников
- [ ] Нижняя панель выбранного участника:
    - Действия: калькулятор урона/лечения/врем.хитов, для скрытого режима — селектор "как выглядит"
      (Цел/Ранен/Изранен/При смерти/Повержен)
    - Состояния: 3 группы (сковывание/ослабление/эффекты), тап переключает вкл/выкл
    - Ещё: смена стороны (враг/нейтрал/друг/сбежал — с автообновлением статуса NPC в кодексе, если участник с ним
      связан), заметка по участнику, "убрать из боя"

## 9. Калькулятор урона/лечения (числовая панель)

- [ ] Режимы: урон / лечение / временные хиты (переключаются табами)
- [ ] Множители ½ (сопротивление) и ×2 (уязвимость) для урона
- [ ] Мультивыбор целей одновременно
- [ ] Построение выражения суммой слагаемых (8 + 6 + 4), живой предпросчёт результата и построчный предпросмотр эффекта
  на каждую цель
- [ ] Переиспользуется также для: ввода инициативы, ввода HP при подготовке к бою, числовых полей формы создания записи
  (уровень/хиты/КД/бонус)
