  NPC показывает расу+фракцию+"где встретить"(ссылка), локация показывает тип, подзаголовок под именем локации —
  регион
- [x] Группы связанных сущностей (у NPC — "выдал квесты", у локации — "кто здесь"/"квесты")
- [x] "Связанные заметки" — автопоиск сессий с упоминанием (см. раздел 3)
- [x] Кнопка-перо (✎) рядом с заголовком — открывает форму создания (раздел 6), предзаполненную данными сущности,

  Кодексе (`CodexUi.kt`); в Дневнике сессий кнопка просто не показывается (параметр `null` по умолчанию) — см.
  обоснование в разделе 6

## 6. Форма создания записи в Кодексе

Реализовано как часть `presentation/codex/` (новый `CodexEntryFormController.kt` + `CodexEntryFormUi.kt`), не как
отдельная Circuit-фича — форма живёт в боттомшите Кодекса, тем же паттерном, что и просмотр сущности
(`CodexState.entryForm`, параллельно существующему `selectedEntity`).

- [x] Форма переиспользуется и для редактирования существующей записи — предзаполняется данными сущности
  (`CodexEntryFormController.onEditEntryRequested`), переключатель типа скрывается (`isEditing`), кнопка сохранения
  правит запись вместо создания новой (`upsert` с существующим `id`)
- [x] Переключатель типа — **NPC/Квест/Место**, без "Отряд": у Отряда до сих пор нет ни доменной модели, ни
  репозитория, ни SQLDelight-схемы (это не тот случай "задел без Impl" из `CombatScratchpad` — там есть полный
  задел, здесь нет вообще ничего), заводить домен Отряда не входило в эту задачу
- [x] Динамические поля по типу:
    - NPC: имя, раса, фракция, статус (чипы), локация (чипы, один выбор), описание
    - Квест: название, кто дал (чипы по NPC, один выбор), награда, где (чипы по локациям, один выбор), статус —
      **без поля "описание"**: в отличие от макета, у реальной `Quest`-модели такого поля нет (`id, title, status,
      reward, givenByNpcId, locationId`), добавлять колонку в БД не входило в эту задачу
    - Локация: название, тип, регион, описание — тут модель полностью совпадает с макетом
    - ~~Отряд~~ — не реализовано, нет домена (см. выше)
- [x] Валидация (кнопка "Сохранить" активна только когда заполнено имя/название)
- [ ] Степпер открывает калькулятор (раздел 8) для быстрого ввода числа — степперы нужны только Отряду (уровень/
  хиты/КД/бонус), которого в форме нет; калькулятор (раздел 9) тоже не начат
