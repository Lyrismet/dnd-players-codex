# Incadent

**English** | [Русский](#русский)

A diary and codex for tabletop RPG players. Android, 5e compatible (SRD 5.1), Russian and English interface.
Coming soon to Google Play.

## Features

- **Sessions**: a diary of notes per game day, `@` mentions of characters, places and quests right in the text, session
  tags.
- **Codex**: party, NPCs, quests and places with portraits, statuses and links between entries.
- **Combat**: a combat tracker with initiative, hit points and results that are saved into the session.
- **Campaigns**: several campaigns with a switcher, archived ones are read-only.
- **Share**: export a session or a campaign for yourself or for a friend.
- Russian and English, dark theme.
- All data stays on your device, no account and no internet needed.

## Install (Android)

1. Open [Releases](../../releases) and download `Incadent-<version>.apk` from the latest release.
2. Open the file on your phone. If the system asks, allow installing from this source.
3. A new version installs over the old one and keeps your data.

## Русский

[English](#incadent) | **Русский**

Дневник и кодекс для игроков в настольные ролевые игры (TTRPG). Совместимо с 5e, правила по SRD 5.1, интерфейс на
русском и английском. Скоро в Google Play.

### Что умеет приложение

- **Сессии**: дневник заметок по дням игры, `@`-упоминания персонажей, мест и квестов прямо в тексте, теги сессий.
- **Кодекс**: отряд, NPC, квесты и места с портретами, статусами и связями между записями.
- **Бой**: трекер боя с инициативой, хитами и итогами, которые сохраняются в сессию.
- **Кампании**: несколько кампаний с переключателем, архивные открываются только для чтения.
- **Поделиться**: экспорт сессии и кампании для себя или для друга.
- Русский и английский язык, тёмная тема.
- Все данные хранятся только на вашем устройстве, без аккаунта и без интернета.

### Установка (Android)

1. Откройте [Releases](../../releases) и скачайте `Incadent-<версия>.apk` из последнего релиза.
2. Откройте файл на телефоне. Если система спросит, разрешите установку из этого источника.
3. Новая версия ставится поверх старой, данные сохраняются.
